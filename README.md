# M-YAGNI

M-YAGNI is a coding skill that balances YAGNI with refactorability.

> Build only what you need now, but make what you build cheap to change later.

## Install

```bash
npx skills add minhquang0407/m-yagni --skill m-yagni
```

Global:
```bash
npx skills add minhquang0407/m-yagni --skill m-yagni -g
```

**Philosophy**

M-YAGNI follows six rules:

1. Concrete First
2. Rule of Three
3. Strategic Boundaries
4. Tactical Simplicity
5. Verification Over Speculation
6. Complexity Must Pay

See [`m-yagni`](./m-yagni) for the complete skill.
